# Coding rules

## 1. Variable names in camelCase
```cpp
int studentCount = 0;
double classAverage = 0.0;
```

## 2. Indentation: 4 spaces
```cpp
if (score < 0 || score > 100) {
    cout << "Invalid score";
}
```

## 3. Meaningful names
Use `averageScore`, not `a` or `x`.
```cpp
double averageScore = totalScore / 5.0;
```

## 4. Comments for important parts of the code
```cpp
// Check that the score is between 0 and 100
```

## 5. One statement per line, maximum line length 80 characters
```cpp
int totalScore = 0;
int studentCount = 0;
```
